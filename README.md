# One-Star Review of Something Essential

One deadpan one-star review of sleep, the everyday essential that keeps
office hours it never agreed to: it shows up late, and it walks out at
3 a.m. without saying goodbye.

## The entry

`main.py` writes one single-line review to `/output/entry.txt` and gates
it the way the bounty does: 1–160 characters, one line, not only
whitespace, then reads the file back to confirm it is exactly the review.

Winner: **"One star. Sleep takes eight hours a night, shows up late, and
leaves at 3 a.m. without saying goodbye."** (102 characters) — the
sharpest true grievance in sleep is the 3 a.m. walkout everyone knows,
and the turn lands in the last few words.

## Run it

```sh
python3 main.py
cat /output/entry.txt   # One star. Sleep takes eight hours a night, ...
```

Python 3.13, standard library only. No network, no dependencies.
